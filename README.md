# Non-redundancy of low-arity Boolean predicates

Source code, test suites and generated data for the paper *Non-redundancy of
low-arity Boolean predicates: classification at arity six and seven, and
barriers for bounded-width gadgets*.

Everything reported in the paper is regenerated by the commands below. No
network access is required.

## Requirements

- A C++20 compiler (`g++` or `clang++`).
- Python 3.9 or later with `python-sat` (`pip install python-sat`).

## Layout

```
src/classification/   arity 6-7 classification sweep
src/gadget/           gadget search (enumerative) and realiser
src/sat/              gadget search (SAT), wsat_t.py adds bounded sources
tests/                two C++ gate suites and three shell drivers
results/              generated tables and logs
```

## Build

```
sh build.sh
```

This produces `bin_test`, `bin_testx`, `bin_sweep`, `bin_est`, `bin_search`,
`bin_analyze` from `src/classification`, and `bin/wsearch`, `bin/wrealize` from
`src/gadget`.

## Validation gates

Run both before trusting any output. Each must print `ALL PASS`.

```
./bin_test        # 80 checks
./bin_testx       # 55 checks
```

`bin_test` covers exactness of the fixed-width arithmetic under a
checked-overflow discipline, agreement of the arbitrary-precision fallback with
the fixed-width path, the closed form of Theorem 3.1 against a direct
construction of the k-cube pattern for all k <= r <= 7, and agreement with the
published tables at every arity up to 5, including recovery of exactly the two
published exceptions at arity 5.

`bin_testx` covers the direct non-redundancy solver, the load-bearing check
being a comparison against brute-force enumeration of all 2^16 subfamilies of
{0,1}^4.

## Reproducing the paper

### Tables 1 and 2 (classification)

```
./bin_sweep 7 > results/table_r7.txt
./bin_sweep 6 > results/table_r6.txt
```

The committed copies were produced this way. Regenerated output is identical
except for the wall-time lines.

### Theorem C (lower bound for R_{0,1,3,4})

Enumerate the width-2 gadgets on 5 positions, then materialise one as an
explicit instance and verify it by brute force:

```
./bin/wsearch --k 5 --s 2 --r 7 --W 0,1,3,4 --u 4 --sym 7 --canon
./bin/wrealize --k 5 --s 2 --r 7 --W 0,1,3,4 --N 11 \
               --pattern 3:8,3:8,3:8,12:8,20:8,24:8,0:0
```

The first prints `orbits=3 total=70`. The second prints
`PROVED-NONREDUNDANT` with zero duplicate variables, zero missing
own-violations and zero foreign violations.

### Table 3 (gadgets for the unresolved predicates)

Run the gadget search on all 36 predicates the classification leaves
unresolved at arity 6 and 7:

```
bash tests/unresolved_sweep.sh            # s=2 then s=3
PHASE=2 bash tests/unresolved_sweep.sh    # s=2 only
```

Output is appended to `results/unresolved_sweep.log`; the file is kept
deduplicated (one line per (predicate, s, k) cell, decided results preferred
over undecided ones from earlier shorter runs) and any rerun should be merged
the same way rather than left to accumulate duplicate lines. `TIMEOUT`
(seconds, default 600), `KMAX` (largest k attempted, default 12) and `PAR`
(parallel workers, default 8) are honoured. Every one of the 36 predicates has
at least one s=2 cell attempted, but the sweep is not fully decided: of the 74
cells in the union of their windows, 60 are unsatisfiable, 4 are satisfiable
and 10 exceeded the time limit. The four satisfiable cells are Table 3 of the
paper. The s=3 phase is far from complete: of its 105 cells, 36 are
unsatisfiable, 5 satisfiable and 64 undecided.

### Table 4 (barriers)

```
bash tests/barriers.sh          # decided cases
FULL=1 bash tests/barriers.sh   # also attempts the undecided cells
```

Output is appended to `results/barriers.log`. Set `TIMEOUT` (seconds, default
600) to change the per-case wall-clock limit.

### Cross-checking a single case

Every gadget decision can be obtained two ways, by SAT and by enumeration.
They share no code, no encoding and no search strategy.

```
python src/sat/wsat_t.py --r 4 --R 0xE917 --k 6 --s 2 --t 5
./bin/wsearch --k 6 --s 2 --r 4 --R 0xE917 --u 3
```

## Command reference

`bin_sweep [max_arity]` runs the classification for arities 1 to `max_arity`
(default 7, maximum 8).

`wsearch` takes a predicate either as a symmetric weight set (`--W 0,1,3,4`) or
as a membership bitmask over the 2^r tuples (`--R 0xE917`), together with
`--k`, `--s`, and optionally `--u` (known upper-bound exponent, used to report
the search-space cap), `--sym D` (symmetry breaking to depth D), `--canon`
(orbit counting), `--emit N` (print up to N witnesses, each re-verified by an
independent path).

`wsat_t.py` takes the same predicate options plus `--k`, `--s` and `--t`. The
value `--t` is the maximum pairwise intersection of the source hypergraph;
omitting it, or passing `-1`, gives the complete source `t = k-1`. The
certified exponent is `(t+1)/s`.

`wrealize` takes `--k --s --r --W --N --pattern` and converts a gadget into an
explicit CSP instance on a pool of `N` elements, then verifies non-redundancy
by brute force over all witness pairs. An entry prints as `mask:ftab`, where
`mask` is the coordinate subset as a bitmask over `[k]` and `ftab` is the truth
table over that subset in increasing assignment order; `3:8` is `AND(v0,v1)`
and `0:0` is the constant `0`.

## Undecided cases

These are recorded as undecided rather than as barriers.

For `W = {0,1,3,4}` at arity 7, the informative window for beating the
`Omega(n^{5/2})` bound is `s=2, k in {6,7,8}`, `s=3, k in {8..12}` and
`s=4, k in {11..16}`. The three cells at `s=2` and the four cells `k in {9..12}`
at `s=3` are unsatisfiable. The cell `s=3, k=8` and the cells
`s=4, k in {11,12,13}` exceeded 90 minutes, and `s=4, k in {14,15,16}` were not
attempted: seven informative cells are open.

In the sweep over the 36 unresolved predicates, every predicate had at least
one `s=2` cell attempted, but 10 of the 74 cells in the union of their windows
remain undecided (60 unsatisfiable, 4 satisfiable). The `s=3` phase covers 105
cells: 36 unsatisfiable, 5 satisfiable, 64 undecided. Both are recorded in
`results/unresolved_sweep.log`.

All other cells of every table in the paper were decided.
